# kiralearn.space

Personal blog of explainer articles, generated by the `/kira-learn` Claude Code skill.

## Architecture

Pure static. Sources live at the repo root; `build-index.js` writes the deploy tree to `dist/`:
- `articles/*.html` — each article is a self-contained HTML file (the source of truth)
- `dist/index.html` — generated clean-grid homepage (served at `/`)
- `dist/sharp.html` — generated typographic feed (served at `/sharp`)
- `dist/articles/`, `dist/favicon.svg`, `dist/robots.txt` — copied from root during build

`dist/` is gitignored — only sources are committed. Vercel runs `node build-index.js` and serves `dist/`.

## Local commands

```bash
npm test           # run unit tests for the renderers
npm run build      # write dist/ from articles/ + static assets
```

## Publishing

The `/kira-learn` skill writes a new article into `articles/`, runs the build, commits sources, and pushes. Vercel auto-deploys on push to `main` once the GitHub integration is connected; until then, deploy with `vercel --prod` from the repo root.

The skill injects `<meta name="article:published" content="YYYY-MM-DD">` into each new article's `<head>`. The build script reads that for sort order, falling back to file mtime when the meta tag is absent (for the original 28 articles imported in the first content commit).
