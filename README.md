# kiralearn.space

Personal blog of explainer articles, generated by the `/kira-learn` Claude Code skill.

## Architecture

Pure static. Each article is a self-contained HTML file in `articles/`. Two homepage variants are regenerated from those articles:
- `index.html` — clean grid (`/`)
- `sharp.html` — typographic feed (`/sharp`)

## Local commands

```bash
npm test           # run unit tests for the build script
npm run build      # regenerate index.html and sharp.html from articles/
```

## Publishing

The `/kira-learn` skill writes a new article into `articles/`, regenerates the index pages, then commits and pushes. Vercel auto-deploys on push to `main`.

If a push fails (offline, auth), the commit stays local. Recover with:
```bash
cd ~/projects/kira-learn
git push
```

If the build step fails after a write, the article HTML is still on disk. Recover with:
```bash
cd ~/projects/kira-learn
node build-index.js
git add . && git commit --amend --no-edit && git push
```

## How articles get added

The `/kira-learn` skill (defined at `~/.claude/skills/kira-learn/SKILL.md`) writes a new article into `articles/`, regenerates `index.html` and `sharp.html`, then commits and pushes. Vercel auto-deploys on push.

The skill injects `<meta name="article:published" content="YYYY-MM-DD">` into each new article's `<head>`. The build script reads that for sort order, falling back to file mtime when the meta tag is absent (for the original 28 articles imported in the first content commit).
